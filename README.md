# 제타 AI 기억력 보조

제타에서 진행한 이야기를 날짜별로 정리하고, 등장인물의 설정과 관계를 기억하며, 과거 서사와 어긋나는 내용을 찾아주는 **기억력 보조 스크립트**입니다.

대화가 길어져도 중요한 사건을 다시 찾아보고, 필요할 때 **모순 정정문**이나 **전체 서사 요약문**을 복사해 제타 채팅에 활용할 수 있습니다.

> 현재 테스트 버전입니다. 일부 기능은 사용 환경에 따라 정상 작동하지 않을 수 있습니다. 중요한 기억은 백업해 두는 것을 권장합니다.

## 설치 방법

1. 브라우저에 **Tampermonkey**를 설치합니다.
2. 아래 링크를 열어 스크립트를 설치합니다.
3. 제타에서 사용할 채팅방을 열고 새로고침합니다.
4. 화면 오른쪽의 **「기억 보조」** 버튼을 누릅니다.

**[제타 AI 기억력 보조 설치하기](https://raw.githubusercontent.com/casualJH/zeta-memory-assistant/main/zeta-memory-assistant.user.js)**

## 처음 사용하는 방법

1. **설정** 탭에서 Gemini API 키를 입력하고 저장합니다.
2. **현황** 탭에서 **「과거 대화 전체 불러오기」**를 누릅니다.
3. 대화 수집이 끝나면 **「미분석 대화 요약」**을 실행합니다. 자동 분석이 켜져 있다면 이후 대화도 자동으로 정리할 수 있습니다.
4. **타임라인**, **인물·관계**, **설정·복선** 탭에서 생성된 기억을 확인합니다.
5. 기억이 잘못 정리된 경우 해당 항목을 직접 수정할 수 있습니다.

Gemini API 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 발급받을 수 있습니다. API 사용량에 따라 요금이 발생할 수 있습니다.

## 기능 소개

### 1. 현황 — 대화 불러오기와 기억 업데이트

- **과거 대화 전체 불러오기:** 채팅방의 첫 대화부터 현재까지 불러옵니다.
- **최신 대화 확인:** 새로 진행한 대화 내용을 추가로 가져옵니다.
- **미분석 대화 요약:** 아직 정리되지 않은 대화를 분석해 기억에 추가합니다.
- **자동 분석 ON/OFF:** 새 대화를 자동으로 정리할지 선택합니다.
- **기억 현황 확인:** 수집한 대화, 저장된 기억, 모순 의심 항목 등을 확인합니다.

채팅방마다 기억이 따로 저장됩니다. 자동 분석을 꺼도 이미 저장된 기억은 그대로 볼 수 있습니다.

### 2. 타임라인 — 날짜별 서사 정리

지금까지 일어난 사건을 시간순으로 정리합니다.

**날짜 표기 기준**

- 이야기 속에서 연도·월·일이 명확하게 나온 경우: **2026년 3월 15일**
- 정확한 날짜가 나오지 않은 경우: **D+1, D+2, D+3…**
- 다음 날, 사흘 뒤 같은 표현이 나오면 이야기 속 시간 흐름에 맞춰 정리합니다.
- 시간 경과가 확실하지 않다면 임의로 날짜를 정하지 않습니다.

실제 채팅을 주고받은 날짜가 아니라 **이야기 속 날짜**를 기준으로 합니다.

**정리 예시**

> **D+1** — 주인공과 민준이 처음 만남.  
> **D+2** — 서로 오해하여 다툼.  
> **D+3** — 오해를 풀고 화해함.

사건을 누르면 연결된 과거 대화 원문을 확인할 수 있습니다.

### 3. 인물·관계 — 캐릭터 기억 관리

등장인물별로 중요한 정보를 정리합니다.

- 이름, 성격, 특징, 가족 관계
- 밝혀진 비밀과 과거 사건
- 다른 인물과의 현재 관계
- 관계나 감정이 변화한 과정

예를 들어 **친구 → 갈등 → 화해 → 연인**처럼 관계가 달라진 과정을 기억할 수 있습니다.

### 4. 설정·복선 — 잊으면 안 되는 내용 보관

이야기를 이어갈 때 중요한 설정과 미해결 사건을 정리합니다.

- **핵심 설정:** 인물의 특징이나 세계관의 중요한 사실
- **설정 고정:** 꼭 유지해야 하는 설정을 직접 지정
- **복선 관리:** 아직 밝혀지지 않은 비밀과 해결되지 않은 사건 기록
- **인물별 지식:** 누가 어떤 사실을 알고 있고, 아직 모르는지 구분
- **기억 중요도:** 핵심·중요·일반·낮음으로 구분

사용자가 직접 수정한 기억은 자동 분석으로 임의 변경되지 않도록 보호합니다.

### 5. 모순 — 설정 오류 확인 및 정정

새로운 AI 답변이 과거 이야기와 충돌하는지 확인하는 기능입니다.

**확인할 수 있는 예시**

- 외동아들이라고 했던 캐릭터에게 갑자기 형제가 생김
- 이미 화해한 일을 처음 겪는 것처럼 이야기함
- 아직 모르는 비밀을 캐릭터가 알고 있는 것처럼 행동함
- 과거 사건의 순서나 인물 관계가 바뀜

모순이 의심되면 **문제가 된 내용, 의심 이유, 과거 원문 근거**를 확인할 수 있습니다.

**「모순 정정문 복사」**를 누르면 잘못된 설정을 바로잡기 위한 문장을 복사할 수 있습니다. 복사한 문장은 제타 채팅에 직접 붙여 넣어 사용합니다.

의도적인 반전이나 거짓말도 오류로 오인할 수 있으므로, 잘못 감지한 항목은 **「오류 아님」**으로 처리할 수 있습니다.

### 6. 기억 검색 — 과거 사건 찾기

잊어버린 내용을 질문으로 검색할 수 있습니다.

**검색 예시**

- “첫 고백이 언제였지?”
- “민준이 비밀을 처음 털어놓은 날은?”
- “둘이 왜 싸웠었지?”
- “아직 해결되지 않은 사건은 뭐야?”

저장된 기록에서 관련 내용을 찾거나, Gemini를 이용해 자연어 답변을 받을 수 있습니다. 가능한 경우 해당 사건의 원문도 함께 확인할 수 있습니다.

### 7. 서사 상기 — 지금까지의 이야기 다시 알려주기

**「전체 서사 상기」**는 지금까지의 주요 사건과 인물 관계, 중요 설정을 정리해 복사하는 기능입니다.

| 분량 | 포함 내용 |
| --- | --- |
| **간략** | 핵심 설정과 가장 중요한 사건 중심 |
| **표준** | 날짜별 주요 사건, 인물 관계, 복선 등 |
| **상세** | 세부 사건, 관계 변화, 인물별 지식까지 최대한 포함 |

원하는 분량을 고르고 **미리보기 → 전체 서사 상기 복사**를 누르면 됩니다.

복사한 요약문은 제타 채팅창에 직접 붙여 넣어 사용합니다. 요약문을 보냈다고 해서 제타 AI가 이를 영구적으로 기억하는 것은 아닙니다.

**「모순 정정」과 「전체 서사 상기」는 서로 다른 기능**입니다.

- **모순 정정:** 지금 잘못 나온 부분을 바로잡을 때 사용
- **전체 서사 상기:** 지금까지의 이야기를 전반적으로 다시 알려줄 때 사용

### 8. 과거 대화 원문 확인

기억 카드나 검색 결과에서 **「원문」**을 누르면 해당 내용이 나온 과거 대화를 볼 수 있습니다.

**「실제 말풍선으로 이동」** 기능도 제공하지만, 오래된 대화가 화면에 불러와지지 않았거나 제타의 화면 구조가 달라진 경우 직접 이동하지 못할 수 있습니다. 이때는 저장된 원문을 열람할 수 있습니다.

### 9. 기억 직접 수정

AI가 기억을 잘못 정리했다면 사용자가 직접 고칠 수 있습니다.

- 날짜별 사건 수정
- 인물 및 관계 정보 수정
- 고정 설정 추가·변경
- 복선 상태 변경
- 잘못된 모순 판단 제외
- 필요 없는 항목 삭제

특히 중요한 설정은 직접 확인하고 고정해 두는 것을 권장합니다.

### 10. 설정 — Gemini와 사용량 관리

**Gemini API 설정**

- API 키 등록·변경·삭제
- **모델 목록 불러오기:** 저장한 API 키로 선택할 수 있는 Gemini 모델 목록 확인
- **모델 선택 메뉴:** Flash-Lite 계열을 먼저 표시하고 원하는 모델 선택
- **직접 입력:** 목록에 없는 모델도 모델 ID를 직접 입력해 설정 가능
- 자동 분석 사용 여부 선택
- API 호출량과 토큰 사용량 확인
- 예상 비용 확인

**무료 API 사용자 안내**

Google AI Studio에서 발급받은 무료 등급 API 키를 사용할 수 있습니다. 처음에는 **Gemini 3.1 Flash-Lite**가 기본으로 선택됩니다. 모델이 작동하지 않으면 **내 API 키의 모델 목록 불러오기 → 원하는 모델 선택 → 모델·요금 설정 저장** 순서로 설정해 주세요.

모델 목록에 나타나더라도 해당 계정에서 무료로 호출할 수 있다고 보장되지는 않습니다. **무료 등급의 사용 가능 모델과 요청 한도는 Google 계정·프로젝트마다 다를 수 있습니다.** 실제 무료 제공 여부는 Google AI Studio에서 확인해 주세요.

**검열 느슨 설정은 항상 ON**으로 적용되며 별도 변경 버튼은 없습니다. 다만 Gemini 서비스 자체의 안전 제한은 적용될 수 있습니다.

예상 비용은 설정된 요금 기준으로 계산되며 실제 청구 금액과 다를 수 있습니다.

### 11. 기억 백업 및 복원

**「이 채팅방 JSON 백업」**을 누르면 해당 채팅방의 원문과 기억을 파일로 저장할 수 있습니다.

**「JSON 복원」**을 사용하면 저장해 둔 기록을 다시 불러올 수 있습니다. 기존 기록을 대체하므로 복원 전 백업을 권장합니다.

- 채팅방별로 따로 저장
- 브라우저를 껐다 켜도 일반적으로 기억 유지
- 다른 기기로 옮길 때는 백업·복원 활용
- API 키는 백업 파일에 포함되지 않음

> 백업 파일에는 실제 대화 내용이 포함될 수 있습니다. 공개적으로 공유하지 않도록 주의해 주세요.

## 사용 전 알아둘 점

- **AI가 정리한 기억은 틀릴 수 있습니다.** 중요한 설정과 인용 내용은 원문을 확인해 주세요.
- 자동 요약과 자연어 답변은 Gemini API를 사용하며, 이용량에 따른 요금이 발생할 수 있습니다.
- Gemini 분석 시 해당 대화 내용이 Google Gemini API로 전송됩니다.
- 스크립트에서 저장한 기억은 기본적으로 현재 브라우저에 보관됩니다. 브라우저 데이터가 삭제되면 기록도 없어질 수 있으므로 정기적인 백업을 권장합니다.
- 현재 테스트 버전이므로 모바일 Safari를 포함한 환경에 따라 일부 기능이 작동하지 않을 수 있습니다.
