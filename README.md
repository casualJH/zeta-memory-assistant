# 제타 기억력 보조

제타에서 진행한 이야기를 날짜별로 정리하고, 등장인물의 설정과 관계를 기억하며, 과거 서사와 어긋나는 내용을 찾아주는 **기억력 보조 스크립트**입니다.

대화가 길어져도 중요한 사건을 다시 찾아보고, 필요할 때 **모순 정정문**이나 **전체 서사 요약문**을 복사해 제타 채팅에 활용할 수 있습니다.

> 현재 테스트 버전입니다. 일부 기능은 사용 환경에 따라 정상 작동하지 않을 수 있습니다. 중요한 기억은 백업해 두는 것을 권장합니다.

## 설치 방법

1. 브라우저에 **Tampermonkey**를 설치합니다.
2. 아래 링크를 열어 스크립트를 설치합니다.
3. 제타에서 사용할 채팅방을 열고 새로고침합니다.
4. 화면 오른쪽의 **「기억 보조」** 버튼을 누릅니다.

**창 크기 조절:** 기억 보조 패널의 네 모서리 중 하나를 마우스나 손가락으로 끌면 가로·세로 크기를 바꿀 수 있습니다. 상단 제목 표시줄을 끌면 창을 이동합니다. 조절한 크기와 위치는 브라우저에 저장되어 새로고침 후에도 유지되며, 화면 크기가 바뀌면 화면 안으로 맞춰집니다. 모바일 Safari에서도 사용할 수 있도록 별도의 모서리 드래그 영역을 사용합니다.

**[제타 기억력 보조 설치하기](https://raw.githubusercontent.com/casualJH/zeta-memory-assistant/main/zeta-memory-assistant.user.js)**

## 처음 사용하는 방법

1. 패널 **오른쪽 상단의 「설정」 버튼**에서 Gemini API 키를 입력하고 저장합니다. 설정 버튼은 이동 표시(↕) 왼쪽에 있습니다.
2. **현황** 탭에서 **「과거 대화 전체 불러오기」**를 누릅니다.
3. 대화 수집이 끝나면 **「미분석 대화 요약」**으로 직접 분석할 수 있습니다. 자동 분석이 켜져 있다면 **미분석 대화가 10개 이상 쌓였을 때** 자동으로 분석합니다.
4. **타임라인**, **인물·관계**, **설정·복선** 탭에서 생성된 기억을 확인합니다.
5. 기억이 잘못 정리된 경우 해당 항목을 직접 수정할 수 있습니다.

Gemini API 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 발급받을 수 있습니다. API 사용량에 따라 요금이 발생할 수 있습니다.

## 기능 소개

### 1. 현황 — 대화 불러오기와 기억 업데이트

- **과거 대화 전체 불러오기:** 채팅방의 첫 대화부터 현재까지 불러옵니다.
- **최신 대화 확인:** 새로 진행한 대화 내용을 추가로 가져옵니다.
- **미분석 대화 요약:** 아직 정리되지 않은 대화를 분석해 기억에 추가합니다.
- **자동 분석 ON/OFF:** 미분석 대화가 10개 이상 쌓이면 자동으로 분석합니다. 1~9개일 때는 기다리고, 원하면 「미분석 대화 요약」으로 바로 수동 분석할 수 있습니다. OOC·요약 등 분석 제외 대화는 10개 기준에 포함하지 않습니다.
- **기억 현황 확인:** 수집한 대화, **미분석 대화 수**, 저장된 기억, 모순 의심 항목 등을 확인합니다.

채팅방마다 기억이 따로 저장됩니다. 자동 분석을 꺼도 이미 저장된 기억은 그대로 볼 수 있습니다.

### 인물·관계 하위 탭과 대화 프로필 저장

**「인물·관계」** 탭 안에 **「인물·관계」 / 「대화 프로필」** 두 하위 탭이 있습니다. 첫 번째 탭에는 기존 인물 카드·현재 감정선·관계 구조가 그대로 표시됩니다.

**「대화 프로필」**에서는 별도 유저스크립트 **「제타 현재 채팅 프로필 자동 감지」**가 감지한 현재 캐릭터, 채팅 프로필, 유저 프로필을 불러올 수 있습니다. 해당 스크립트를 함께 설치하고 제타 채팅방에서 프로필 정보가 표시된 상태에서 **「대화 프로필 불러오기」**를 눌러 주세요. 수집되지 않은 항목은 미수집 상태로 표시됩니다.

**한 번 불러오면 채팅방별로 브라우저의 로컬 저장소(IndexedDB)에 저장**됩니다. 새로고침하거나 프로필 감지 스크립트가 일시적으로 실행되지 않아도 저장된 프로필을 볼 수 있습니다. 변경된 프로필로 교체하려면 **「대화 프로필 다시 불러오기」**를 눌러 주세요. 기억·요약 JSON 백업에도 저장된 프로필을 포함합니다. 이 프로필은 현재 **표시·보관용**이며 Gemini 분석 요청에 자동으로 전송되지 않습니다.

### 2. 타임라인 — 날짜별 서사 정리

지금까지 일어난 사건을 시간순으로 정리합니다.

**날짜 표기 기준**

- 이야기 속에서 연도·월·일이 명확하게 나온 경우: **2026년 3월 15일**
- 정확한 날짜가 나오지 않은 경우: **D+1, D+2, D+3…**
- 다음 날, 사흘 뒤 같은 표현이 나오면 이야기 속 시간 흐름에 맞춰 정리합니다.
- 시간 경과가 확실하지 않다면 임의로 날짜를 정하지 않습니다.

실제 채팅을 주고받은 날짜가 아니라 **이야기 속 날짜**를 기준으로 합니다.

**정리 예시**

> **D+1** — 주인공과 민준이 처음 만남.  
> **D+2** — 서로 오해하여 다툼.  
> **D+3** — 오해를 풀고 화해함.

**OOC·요약 메시지 자동 제외:** 메시지 내용에 `ooc:`(대소문자 구분 없음, 콜론 앞 공백 허용) 또는 `요약`이 포함되면 해당 메시지 전체를 Gemini 분석에서 제외합니다. 일반 RP 대화라도 이 단어가 들어 있다면 제외되므로 주의하세요. 제외된 대화는 브라우저의 원문 저장소에 남지만, 기억·요약 결과만 내보내는 JSON 백업에는 포함되지 않습니다. 기존에 분석한 내용에는 소급 적용되지 않으므로 필요한 경우 초기화 후 재분석하세요.

**타임라인 사건 구분:** '임신·러트·결혼'처럼 여러 장면에 걸친 큰 **서사 주제**와 개별 **사건**을 구분합니다. 식사 중 임신 가능성 및 테스트기 반응, 병원 진료·검사·확진, 귀가 후 준비, 각방 갈등, 취침과 안정처럼 별개의 당면 목표나 갈등은 사건을 나누되, 하나의 진료를 위한 검사·대기·확진 절차나 한 번의 친구 제안에 대한 반응은 불필요하게 쪼개지 않습니다. 사건명은 각 항목 전체에 들어맞도록 기록합니다. 직전 사건과 자동 통합하는 경우에도 구체적인 사건 식별자가 일치해야 하며, 추가 Gemini 호출은 없습니다. 기존 기억은 그대로 보존되고 새로운 기준을 과거 기록에 적용하려면 백업 후 재분석해야 합니다.

회상이나 나중에 밝혀진 과거 사건은 현재 사건과 구분하고, 원문 근거와 명시된 이야기 날짜를 바탕으로 시간순으로 표시합니다. 정확한 날짜가 없으면 임의의 날짜를 만들지 않습니다. 과거 사건의 실제 발생 시점과 그 사실이 공개된 시점은 다를 수 있습니다.

타임라인 맨 위의 **현재 장면**에는 최근까지 진행된 장소, 인물, 갈등과 마지막 상황이 표시됩니다.

**「원문 전체 보기 (N개)」** 버튼을 누르면 해당 사건에 연결된 원문을 모두 확인할 수 있습니다.

**여러 사건 합치기·날짜 일괄 수정:** 타임라인 상단의 **「사건 합치기 · 날짜 일괄 수정」** 버튼을 누르면 사건마다 선택 체크박스가 나옵니다. 사건을 여러 개 선택하여 **「선택 사건 합치기」**를 누르면 인접한 같은 날짜·시간 유형의 사건을 하나의 항목으로 묶고 모든 서술과 출처를 유지합니다. 서술을 더 다듬으려면 합친 사건의 **「편집」**을 사용하세요.

여러 사건의 날짜는 체크한 뒤 **실제 날짜(YYYYMMDD 숫자 8자리 입력)** 또는 **이야기 날짜(D+N)**를 정하고 **「선택 사건 날짜 적용」**을 누르면 한 번에 변경됩니다. 예: `20250412` → `2025년 4월 12일`. 존재하지 않는 날짜는 저장되지 않습니다. 연속된 구간 전체를 선택하려면 처음과 마지막 사건 두 개만 체크한 뒤 **「사이 전체 선택」**을 누르세요. 선택하지 않은 사건의 날짜는 변하지 않으며 수동 수정 내용은 자동 분석에서 보호됩니다. 이야기 시작일을 별도로 지정하는 기능은 추가하지 않았으며 기존 D+1 기준을 유지합니다.

### 3. 인물·관계 — 캐릭터 기억 관리

등장인물별로 중요한 정보를 정리합니다.

- 이름, 성격, 특징, 가족 관계
- 밝혀진 비밀과 과거 사건
- 다른 인물과의 현재 관계
- 관계나 감정이 변화한 과정

예를 들어 **친구 → 갈등 → 화해 → 연인**처럼 관계가 달라진 과정을 기억할 수 있습니다.

**현재 감정선**에서는 각 인물이 상대에게 느끼는 지속적인 감정과 이유, 현재 행동 패턴을 따로 관리합니다. 명시된 감정과 행동에서 해석한 감정을 구분합니다. **현재 관계 구조**에는 관계 단계, 신뢰·갈등 해결 방식, 인식 차이를 기록합니다.

### 4. 설정·복선 — 잊으면 안 되는 내용 보관

이야기를 이어갈 때 중요한 설정과 미해결 사건을 정리합니다.

- **핵심 설정:** 인물의 특징이나 세계관의 중요한 사실
- **설정 고정:** 꼭 유지해야 하는 설정을 직접 지정
- **복선 관리:** 아직 밝혀지지 않은 비밀과 해결되지 않은 사건 기록
- **인물별 지식:** 누가 어떤 사실을 알고 있고, 아직 모르는지 구분
- **기억 중요도:** 핵심·중요·일반·낮음으로 구분

사용자가 직접 수정한 기억은 자동 분석으로 임의 변경되지 않도록 보호합니다.

### 5. 모순 — 설정 오류 확인 및 정정

**제타 AI가 이전에 확정된 서사 사실을 잘못 기억하고 다르게 출력했는지** 확인하는 기능입니다. 인물의 논쟁이나 말과 속마음이 다른 상황을 분석하는 기능이 아닙니다.

**확인할 수 있는 예시**

- 외동아들이라고 했던 캐릭터에게 갑자기 형제가 생김
- 이미 화해한 일을 처음 겪는 것처럼 이야기함
- 아직 모르는 비밀을 캐릭터가 알고 있는 것처럼 행동함
- 과거 사건의 순서나 인물 관계가 바뀜

모순이 의심되면 **문제가 된 내용, 의심 이유, 과거 원문 근거**를 확인할 수 있습니다.

**「모순 정정문 복사」**를 누르면 잘못된 설정을 바로잡기 위한 문장을 복사할 수 있습니다. 복사한 문장은 제타 채팅에 직접 붙여 넣어 사용합니다.

캐릭터의 거짓말·변명·플러팅·주관적인 반박·감정 변화는 원칙적으로 모순 감지에서 제외합니다. 감지할 때는 **과거 확정 원문과 이후 AI 객관적 지문의 근거가 모두 확인**되어야 합니다. 그래도 판단이 잘못되었다면 **「오류 아님」**으로 처리할 수 있습니다. 변경 전에 생성된 의심 기록은 자동으로 삭제되지 않습니다.

### 6. 기억 검색 — 과거 사건 찾기

잊어버린 내용을 질문으로 검색할 수 있습니다.

**검색 예시**

- “첫 고백이 언제였지?”
- “민준이 비밀을 처음 털어놓은 날은?”
- “둘이 왜 싸웠었지?”
- “아직 해결되지 않은 사건은 뭐야?”

저장된 기록에서 관련 내용을 찾거나, Gemini를 이용해 자연어 답변을 받을 수 있습니다. 가능한 경우 해당 사건의 원문도 함께 확인할 수 있습니다.

### 7. 서사 상기 — 지금까지의 이야기 다시 알려주기

**「전체 서사 상기」**는 지금까지의 주요 사건과 인물 관계, 중요 설정을 정리해 복사하는 기능입니다.

| 분량 | 포함 내용 |
| --- | --- |
| **간략** | 주요 서사와 현재 상황을 간결하게 요약. 4,500자 이내 |
| **표준** | 전체 사건 흐름·인물 관계·감정선·미해결 변수 중심으로 약 4,500자 요약 (최대 4,500자) |
| **상세** | 모든 저장 기억을 글자 수 제한 없이 출력 |

원하는 분량을 고르고 **미리보기** 또는 **전체 서사 상기 복사**를 누르면 됩니다. **간략·표준은 Gemini가 저장된 전체 기억을 검토하고 내용을 통합해서 요약**합니다. 분량을 맞추기 위해 뒤쪽 내용을 단순 삭제하지 않습니다. 4,500자 이내로 요약되지 않으면 무조건 자르지 않고 생성 실패를 알립니다.

**간략·표준은 Gemini API 호출이 발생**하므로 무료 등급의 요청 한도에 영향을 줄 수 있습니다. **상세는 별도 API 호출 없이 저장된 전체 기억을 글자 수 제한 없이 출력**합니다. 이미 만든 간략·표준 요약은 기억이 바뀌지 않았다면 다시 사용할 수 있습니다.

복사한 요약문은 제타 채팅창에 직접 붙여 넣어 사용합니다. 요약문을 보냈다고 해서 제타 AI가 이를 영구적으로 기억하는 것은 아닙니다.

서사 상기문에는 저장된 현재 장면과 감정선·관계 구조·미해결 변수를 함께 담습니다. 기억을 저장할 때는 세부 정보를 보존하며, **복사본의 길이 제한은 간략·표준에만 적용**됩니다. 긴 이야기는 단계적으로 읽고 요약을 통합하므로 API 요청이 여러 번 발생할 수 있습니다.

**「모순 정정」과 「전체 서사 상기」는 서로 다른 기능**입니다.

- **모순 정정:** 지금 잘못 나온 부분을 바로잡을 때 사용
- **전체 서사 상기:** 지금까지의 이야기를 전반적으로 다시 알려줄 때 사용

### 8. 과거 대화 원문 확인

기억 카드나 검색 결과에서 **「원문 전체 보기 (N개)」**를 누르면 **해당 카드에 연결된 원문 전체**를 한 화면에서 볼 수 있습니다. 각 원문은 별도로 복사하거나 해당 말풍선으로 이동할 수 있습니다. **「기억 목록으로 돌아가기」**를 누르면 이전 화면으로 돌아갑니다.

**「실제 말풍선으로 이동」** 기능도 제공하지만, 오래된 대화가 화면에 불러와지지 않았거나 제타의 화면 구조가 달라진 경우 직접 이동하지 못할 수 있습니다. 이때는 저장된 원문을 열람할 수 있습니다.

### 9. 기억 직접 수정

AI가 기억을 잘못 정리했다면 사용자가 직접 고칠 수 있습니다.

- 날짜별 사건 수정
- 인물 및 관계 정보 수정
- 고정 설정 추가·변경
- 복선 상태 변경
- 잘못된 모순 판단 제외
- 필요 없는 항목 삭제
- **전체 재분석 시 수동 기억·고정 지침 유지 또는 전체 초기화 선택**

특히 중요한 설정은 직접 확인하고 고정해 두는 것을 권장합니다.

### 10. 설정 — Gemini와 사용량 관리

**Gemini API 설정**

- API 키 등록·변경·삭제
- **모델 목록 불러오기:** 저장한 API 키로 선택할 수 있는 Gemini 모델 목록 확인
- **모델 선택 메뉴:** Flash-Lite 계열을 먼저 표시하고 원하는 모델 선택
- **직접 입력:** 목록에 없는 모델도 모델 ID를 직접 입력해 설정 가능
- 자동 분석 사용 여부 선택
- **무료 등급 기본 설정:** 모델을 고른 후 요금 입력 없이 바로 저장
- **유료 API 선택 시에만** 입력·출력 토큰 요금과 예상 비용 표시
- API 호출량과 토큰 사용량 확인

**무료 API 사용자 안내**

Google AI Studio에서 발급받은 무료 등급 API 키를 사용할 수 있습니다. 처음에는 **Gemini 3.1 Flash-Lite**가 기본으로 선택됩니다. 모델이 작동하지 않으면 **내 API 키의 모델 목록 불러오기 → 원하는 모델 선택 → 모델·요금 설정 저장** 순서로 설정해 주세요.

모델 목록에 나타나더라도 해당 계정에서 무료로 호출할 수 있다고 보장되지는 않습니다. **무료 등급의 사용 가능 모델과 요청 한도는 Google 계정·프로젝트마다 다를 수 있습니다.** 실제 무료 제공 여부는 Google AI Studio에서 확인해 주세요.

**검열 느슨 설정은 항상 ON**으로 적용되며 별도 변경 버튼은 없습니다. 다만 Gemini 서비스 자체의 안전 제한은 적용될 수 있습니다.

무료 등급을 선택하면 요금 입력란과 비용 추정이 표시되지 않습니다. 유료 API 사용자는 이용 방식을 **유료 API**로 바꿔 요금을 입력할 수 있습니다. 이 선택은 Google 계정의 결제 상태를 변경하지 않습니다. 유료 예상 비용은 실제 청구 금액과 다를 수 있습니다.

### 11. 기억 초기화 및 재분석

**현황 → 분석 다시 시작**에서 두 가지 방식을 선택할 수 있습니다.

- **체크하지 않음 (기본):** AI가 생성한 기억을 초기화하되, 사용자가 직접 수정·추가하거나 고정한 내용은 유지합니다.
- **「수동 편집·직접 추가한 기억·고정 지침도 함께 초기화」 체크:** 수동 내용까지 포함하여 **모든 기억과 고정 지침을 초기화**합니다.

어느 방법이든 **대화 원문은 삭제하지 않습니다.** 초기화한 뒤 **현황 → 미분석 대화 요약**을 누르면 처음부터 다시 정리합니다. 중요한 기록은 초기화 전에 백업하세요.

### 12. 기억 백업 및 복원

**「기억·요약 결과 백업」**을 누르면 이 스크립트에서 생성하거나 직접 편집·고정한 기억을 JSON 파일로 저장할 수 있습니다. 타임라인·인물·관계·감정선·설정·복선·모순·분석 진행 기록 등이 포함되며 **대화 원문 전체는 포함하지 않습니다.**

**「기억·요약 결과 복원」**을 사용하면 같은 채팅방에 저장된 기억을 백업 내용으로 대체합니다. **로컬에 수집된 대화 원문은 유지**됩니다. 이전 버전의 전체 백업 파일도 기억 부분만 복원할 수 있습니다.

- 채팅방별로 따로 저장
- 브라우저를 껐다 켜도 일반적으로 기억 유지
- 다른 기기로 옮길 때는 백업·복원 활용. 원문 출처를 확인하려면 새 기기에서 과거 대화 전체 불러오기를 실행해야 함
- API 키는 백업 파일에 포함되지 않음

> 백업 파일에는 원문 전문이 없지만 기억과 요약에 대화 내용이나 인용문, 인물 정보가 포함될 수 있습니다. 공개적으로 공유하지 않도록 주의해 주세요.

## 사용 전 알아둘 점

- **AI가 정리한 기억은 틀릴 수 있습니다.** 중요한 설정과 인용 내용은 원문을 확인해 주세요.
- 자동 요약과 자연어 답변은 Gemini API를 사용하며, 이용량에 따른 요금이 발생할 수 있습니다.
- Gemini 분석 시 해당 대화 내용이 Google Gemini API로 전송됩니다.
- 스크립트에서 저장한 기억은 기본적으로 현재 브라우저에 보관됩니다. 브라우저 데이터가 삭제되면 기록도 없어질 수 있으므로 정기적인 백업을 권장합니다.
- 현재 테스트 버전이므로 모바일 Safari를 포함한 환경에 따라 일부 기능이 작동하지 않을 수 있습니다.
